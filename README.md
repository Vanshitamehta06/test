# Page For Password Reset — Login

Interactive sign-in and sign-up page with a FastAPI backend.

Generated by Intent2Deploy AI from the request: "create a page for password reset . just the frontend".

## Run

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8129
```

Open http://127.0.0.1:8129.

**Where it runs:** http://127.0.0.1:8129 — Intent2Deploy's staging preview serves this project on port 8129 (this project's own port), and the commands here use the same address. If you run it yourself while the preview is running, stop the preview first or use another port (e.g. `--port 8020`).

## Test

```bash
python -m pytest -q
```

## Notes

- Passwords are hashed with PBKDF2-SHA256 and a per-user salt.
- Accounts and sessions are kept in memory; add a database and token expiry before production use.

## Docker

Build and run the image:

```bash
docker build -t page-for-password-reset-login .
docker run --rm -p 8129:8000 page-for-password-reset-login
```

Or with Docker Compose:

```bash
docker compose up --build
```

Then open http://127.0.0.1:8129
(health check: http://127.0.0.1:8129/health). If port 8129 is busy, change
the left side of the port mapping (e.g. `-p 8020:8000`).
This is the same address Intent2Deploy's staging preview uses for this project (port 8129); stop the preview first if you run the container yourself.

CI builds this image and checks the running container on every pull request and after each merge
into `staging` and `main` (`.github/workflows/docker.yml`).
